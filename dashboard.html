System Architecture

intake.py

Scans input_invoices/ for new files. Validates format (PNG, JPG, TIFF, PDF) and integrity via Pillow. SHA-256 deduplication. Filename sanitization against path traversal.

ocr.py

OpenCV preprocessing: grayscale → Gaussian denoise → CLAHE contrast → deskew → adaptive threshold. Tesseract 5.4.0 extraction. PDF→image via Poppler/pdf2image. Saves raw text to ocr_output/.

parser.py

Regex/heuristic extraction of invoice number, date (multi-format), vendor name, total + currency, line items. Confidence scoring: high / medium / low based on field coverage.

storage.py

Server-side validation of all parsed fields before insert. SQLite storage into invoice_documents + invoice_line_items. Moves processed files. Query helpers for reporting.

config.py

Loads .env via python-dotenv. Paths: INPUT_DIR, PROCESSED_DIR, FAILED_DIR, OCR_OUTPUT_DIR, DATABASE_PATH. Tesseract + Poppler paths. SMTP settings for notifications.

db.py

SQLite schema with versioned migrations (v1). Tables: schema_version, invoice_documents, invoice_line_items, processing_logs. Foreign keys and indexes enabled.

Setup Guide
1 Install Tesseract OCR
Download from github.com/UB-Mannheim/tesseract/wiki and install.
Default path: C:\Program Files\Tesseract-OCR\tesseract.exe
2 Install Poppler (PDF support)
Only needed for PDF invoices. Download from github.com/oschwartz10612/poppler-windows/releases.
Extract and add the bin folder to PATH, or set POPPLER_PATH in .env.
3 Python Environment
python -m venv venv .\venv\Scripts\activate pip install -r requirements.txt
4 Configure .env
TESSERACT_CMD=C:\Program Files\Tesseract-OCR\tesseract.exe POPPLER_PATH= DATABASE_PATH=data/invoices.db
5 Initialize Database
python init_db.py
Creates the SQLite database with schema v1 (invoice_documents, invoice_line_items, processing_logs).
6 Run the Pipeline
# Generate a test invoice python create_test_file.py # Process all invoices in input_invoices/ python run_pipeline.py
Drop real invoices (.png, .jpg, .pdf, .tiff) into input_invoices/ and run the pipeline.
